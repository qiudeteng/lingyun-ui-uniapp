# 404 Demo

演示页面：`/pages/404/404`

缺失页面示例：`lingyun-app-page` + `lingyun-empty` 组合出的整页 404，路由不存在 / 没有权限时由业务或宿主跳到这里。

## 结构

- 整页居中空态：大标题「404」+ 说明文字 + 「返回首页」主按钮。
- 支持 `?from=<路径>` 查询参数：说明文字第二行会显示缺失的来源路径（小程序宽屏宿主里从 `pageHostState.url` 同步）。
- 返回首页：清掉导航意图后回首页；宽屏小程序宿主内通过 `openLingyunHostedPage` 换页，不增加页面栈。

## 使用

```ts
// 业务里发现路径不可用 / 无权限时
uni.redirectTo({ url: '/pages/404/404?from=' + encodeURIComponent(currentPath) })
```

宽屏（小程序宿主 / H5 侧栏）点到未注册页面时，宿主会自动用 `lingyun-page-miss` 在内容区展示同样的空态，不必自己跳 404 页。`lingyun-page-miss` 是页面壳内部组件，业务一般不需要直接用。
