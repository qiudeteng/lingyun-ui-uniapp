# Steps 规范（强制 · lingyun-steps）

> 流程步骤条：横向 / 纵向、完成 / 进行中 / 等待 / 错误、可点击切换。
> 用于下单、制作、配送、审批等流程进度展示。

## 1. 结构

```text
步骤条（内容层，非玻璃）
├── 步骤项 × n
│   ├── 状态圆点（28px）
│   ├── 连接线（2px，圆点中心到下一圆点中心）
│   └── 标题 / 说明
```

- 内容层标准材质，不铺 Liquid Glass；通常放在 `lingyun-section` 分组卡片内。
- 横向步骤等宽排列，步骤多时横向滚动；纵向步骤由页面自然滚动。
- 连接线在圆点下方，圆点在线上层；已完成步骤后的连接线用主色。

## 2. 尺寸

| 项 | 规格 |
|----|------|
| 圆点 | 28px，圆形；完成 / 进行中主色，等待 Fill Tertiary，错误 System Red |
| 圆点内容 | 数字 13/18，600；完成用 16px 勾选，错误用 16px 关闭 |
| 连接线 | 2px；未完成 Separator，已完成主色 |
| 标题 | 15/20；进行中 600、完成 500、等待 400 |
| 说明 | 12/16，Secondary；横向单行省略，纵向可换行 |
| 横向项宽 | 等宽，最小 84px，左右内边距 6px |
| 横向间距 | 圆点上 0，标题距圆点 6px |
| 纵向间距 | 圆点与文字 12px；每步底部 16px |
| 纵向连接线 | 距左 13px，从圆点底部到下一步顶部 |
| 点击态 | 透明度 0.72；禁用 0.4 且不可点击 |

## 3. 状态

| 状态 | 表现 |
|------|------|
| `wait` 等待 | 灰底圆点 + 灰色数字；标题 / 说明 Secondary |
| `process` 进行中 | 主色圆点 + 白色数字；标题 Label / 600 |
| `finish` 完成 | 主色圆点 + 白色勾选；标题 Label / 500；下方连接线主色 |
| `error` 错误 | System Red 圆点 + 白色关闭；标题红色 |
| 禁用 | 0.4 透明度；不响应点击 |

- 默认按 `v-model` 推导：`index < current` 为完成，等于当前为进行中，之后为等待。
- 每项可用 `status` 显式覆盖（错误、强制完成等）。
- `v-model` 可传步骤 key 或索引。

## 4. 方向与滚动

- `horizontal`：等宽步骤，圆点在上、文字在下；步骤多时用 `scroll-view scroll-x`，不换行。
- `vertical`：圆点在左、文字在右；说明可多行，适合审批 / 轨迹。
- `scrollable=false` 时横向不滚动，超出部分由容器裁切。

## 5. 交互

- `clickable` 时整步可点，切换 `v-model` 并抛 `change({ key, index, item })`。
- 被禁用的步骤不响应点击，也不参与键盘 / 触控切换。
- 提供 `select()` / `next()` / `prev()` 方法，便于底部按钮控制流程。
- `#icon` 插槽可替换默认数字 / 勾选 / 关闭图标，作用域 `{ item, index, status }`。

## 6. 颜色与暗黑

- 默认主色 System Blue，可用 `accentColor` 覆盖；只影响进行中 / 完成圆点与已完成连接线。
- 错误统一 System Red，不跟随主色。
- 暗黑下标题、说明、连接线跟随主题变量；圆点主色保持不变。
