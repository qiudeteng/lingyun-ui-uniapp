# lingyun-tag

静态标签，用来标状态。可点选的胶囊用 `lingyun-chip`。

## 示例

```vue
<lingyun-tag text="进行中" color="blue" />
<lingyun-tag text="完成" variant="outline" color="green" />
```

## 属性

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `text` | 文案 | '' |
| `variant` | `fill` 填充或 `outline` 描边 | fill |
| `color` | `blue` / `green` / `orange` / `red` / `gray` | blue |
