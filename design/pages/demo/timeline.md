# Timeline Demo

对应页面：`src/pages/demo/timeline.vue`

## 区块

1. `hero`：标题 Timeline + 说明「纵向时间线 · 订单轨迹 / 操作日志 · 状态与图标」。
2. `订单轨迹`：4 条物流节点，时间 / 说明 / 成功 / 进行中状态，带图标圆点。
3. `审批日志`：成功 / 进行中 / 警告 / 错误四种状态，最后一条带关闭图标。
4. `可点击`：同一个订单轨迹，开启 `clickable`，点击后显示最近操作。
5. `空态`：`items=[]` + 自定义空文案。
6. `最近操作`：显示 `item-click` 结果。

## 规范

- 组件规格见 [`TIMELINE.md`](../../TIMELINE.md)。
- 页面只负责示例数据与事件展示。
