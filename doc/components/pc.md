# lingyun-pc

窗口宽度达到 690 时显示插槽内容。平板和电脑都算，窄屏不渲染。演示：`/pages/demo/responsive`。

## 示例

```vue
<lingyun-pc>
  <lingyun-section title="平板和电脑上的内容" />
</lingyun-pc>
```

和 `lingyun-mobile` 成对使用。窗口窄于 690 时，这一支隐藏。
