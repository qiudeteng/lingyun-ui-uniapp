# Rating 规范（强制 · lingyun-rating）

> 评分控件：整星 / 半星、只读 / 禁用、可清除、显示分值。
> 用于评价、满意度、门店打分。

## 1. 结构

```text
评分（内容层，非玻璃）
├── 星星行（inline-flex）
│   └── 每颗星：未激活星底 + 按百分比裁剪的激活星 + 点击热区
└── 分值文字（可选）
```

- 不画星星背景卡片；星星直接放在表单行 / 分组卡片内。
- 每颗星由「灰色空心星」+「按宽度裁剪的实心星」叠加，半星就是 50% 裁剪。
- 半星点击热区左右各 50%，整星点击时整颗热区。

## 2. 尺寸

| 项 | 规格 |
|----|------|
| 星星尺寸 | 默认 24px，可配置 12–48px |
| 星星间距 | 默认 4px |
| 默认激活色 | System Orange（`orange` / `#ff8d28`） |
| 默认未激活色 | Gray 3（`gray3` / `#c7c7cc`） |
| 分值文字 | 13/18，Secondary，距星星 6px |
| 热区 | 覆盖整颗星；半星时左右各 50% |
| 禁用 | 0.4 透明度，不响应点击 |

## 3. 状态

| 状态 | 表现 |
|------|------|
| 可编辑 | 星星可点，半星左右热区生效 |
| 只读 | 只展示分值，不显示热区 |
| 禁用 | 0.4 透明度，无热区，不响应 |
| 可清除 | `clearable` 时再次点击当前分值归零 |
| 半星 | `allowHalf` 时支持 0.5 步进，显示半颗实心星 |

- `modelValue` 会被限制在 0–max；`allowHalf=false` 时向下取整。
- `showValue` 时显示当前分值；`valueSuffix` 可追加「/ 5」等文案。

## 4. 交互

- 移动端在星星行上**左右滑动**调整分值，按半星 / 整星步进取值；滑动时阻止页面滚动。
- H5 同时支持鼠标在星星行上左右拖动；只读 / 禁用时不拦截页面滚动。
- 点击第 N 颗星左半区得到 `N - 0.5`，右半区得到 `N`；整星模式点击得到 `N`。
- `clearable`：点击与当前值相同的分值归零；拖动不会触发清除。
- 键盘 / 读屏：星星行使用 `radiogroup`，每颗星带当前值与标签；业务可在外层再提供说明。
- 星星使用字体图标，不引入图片资源。
