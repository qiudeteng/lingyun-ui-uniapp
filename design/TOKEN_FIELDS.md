# Token Field 规范（强制 · lingyun-token-field）

> 多选标签输入：回车 / 分隔符添加、建议、去重、上限。
> 用于商品标签、活动类型、门店分组等。

## 1. 结构

```text
Token Field
├── 标签（可选）
├── 输入容器
│   ├── 已选 token × n（可移除）
│   ├── 输入框
│   └── 数量（可选）
└── 建议列表（可选）
```

- 输入容器是内容层标准字段；建议列表是内容层卡片，不做浮层。
- token 为紧凑胶囊，不嵌套玻璃。

## 2. 尺寸

| 项 | 规格 |
|----|------|
| 容器最小高度 | 48px |
| 容器内边距 | 6×8，圆角 12 |
| token | 高 28，圆角 14，左右内边距 8×4 |
| token 文案 | 13/18，Label |
| token 关闭 | 20px 圆形 |
| 输入框 | 高 32，15/20，最小宽 90 |
| 标签 | 12/16，Secondary |
| 建议行 | 最小 40，左右 12，14/20 |
| 数量 | 12/16，Tertiary |
| 聚焦 | 1px 主色内描边 |
| 禁用 / 只读 | 0.5 透明度 |

## 3. 行为

- 回车 / 失焦（`addOnBlur`）/ 输入逗号或中文逗号添加 token。
- `max > 0` 时达到上限抛 `invalid(reason=max)`；不再添加。
- 默认不允许重复（精确匹配）；`allowDuplicate=true` 可重复。
- `allowCustom=false` 时只能选择 `suggestions` 中的项，否则抛 `invalid(reason=custom)`。
- 建议按输入过滤，最多 6 条；已选 token 不再出现。
- 点击建议添加；点击 token 关闭移除。
- 只读不显示输入框与移除钮；禁用整体不可交互。
