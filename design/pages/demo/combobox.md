# Combobox Demo

对应页面：`src/pages/demo/combobox.vue`

## 区块

1. `hero`：标题 Combobox + 说明「可搜索选择 · 字段触发 + 搜索列表」。
2. `基础选择`：门店列表、可清除、可搜索，展示搜索 / 打开 / 关闭 / 选择事件。
3. `带说明`：配送方式，选项带 description，含禁用项。
4. `禁用 / 只读`：同一门店的禁用与只读回显。
5. `最近操作`：选择 / 清除 / 搜索 / 开关。

## 规范

- 组件规格见 [`COMBOBOX.md`](../../COMBOBOX.md)。
- 页面只负责示例数据与事件。
