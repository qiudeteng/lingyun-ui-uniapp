# 凌云UI Charts

凌云UI 图表组件库。标签 `<lingyun-ui-charts />`。当前版本 **1.0.25**。
引擎、配色和默认配置与组件放在同一目录。只使用本包引擎，不支持 ECharts。

📖 [使用手册](https://lingyun.xinyicanyin.com/charts/)（组件用法、属性、示例；右侧手机框实时预览）

📦 [仓库](https://github.com/qiudeteng/lingyun-ui-uniapp)

🐛 欢迎反馈：使用中遇到问题或有建议，请在 [仓库 Issues](https://github.com/qiudeteng/lingyun-ui-uniapp/issues) 提交，也欢迎 PR 共同完善。

```vue
<lingyun-ui-charts type="column" :chartData="chartData" :opts="chartOpts" />
```
