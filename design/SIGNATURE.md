# Signature 规范（强制 · lingyun-signature）

> 手写签名板：触控 / 鼠标绘制、清除、重新签名、导出 PNG。
> 用于送货签收、门店确认、审批等需要手写确认的场景。

## 1. 结构

```text
标准材质卡片（内容层，非玻璃）
├── 标题 / 说明
├── 签名画布（白纸，圆角 12，内描边）
│   ├── 空态占位「请在此签名」
│   ├── 已签名预览（重新签名前覆盖画布）
│   └── 导出中覆盖层
└── 操作区：清除 / 重新签名 + 完成
```

- 画布是**内容层**，使用标准材质，不铺 Liquid Glass；卡片按分组卡片标准材质。
- 画布不显示网格、下划线或水印，避免被一起导出到签名图片。
- 已完成签名以图片预览覆盖画布；点「重新签名」清空后重新绘制。

## 2. 尺寸

| 项 | 规格 |
|----|------|
| 卡片圆角 | 16px |
| 卡片内边距 | 14px |
| 标题 | 17/22，600，Label |
| 说明 | 13/18，Secondary |
| 画布高度 | 默认 180px，最小 120px |
| 画布圆角 | 12px |
| 画布背景 | 默认 `#ffffff`；可传 `transparent` 导出透明 PNG |
| 画布描边 | 内侧 1px Separator |
| 签笔 | 默认 3px，`#1c1c1e`，圆头圆角；可配置 1–12px |
| 操作区 | 距画布 12px，左右分布；文字按钮 44px 点击区 |
| 完成按钮 | `lingyun-button` small / borderedProminent |
| 占位文字 | 15/22，固定浅灰 `rgba(60, 60, 67, 0.3)`，水平垂直居中；画布始终白纸，不跟随暗黑 Tertiary |

## 3. 状态

| 状态 | 表现 |
|------|------|
| 空 | 显示占位文字；「清除」置灰；「完成」置灰 |
| 绘制中 | 隐藏占位；笔画实时跟随；页面不跟随滚动 |
| 已签名 | 显示 PNG 预览；操作区变为「重新签名」 |
| 导出中 | 画布上覆盖标准材质加载层，操作不可点 |
| 只读 | 只展示已有签名预览或占位，不显示操作区 |
| 禁用 | 同只读，整体 0.6 透明度 |

## 4. 交互

- `v-model` 是 PNG 地址（H5 为 data URL，小程序为临时文件路径）；确认后回写。
- 支持触摸与 H5 鼠标绘制；每次只画一条连续笔画，笔画坐标按画布归一化，尺寸变化后重绘。
- 「清除」清空笔画并回写空字符串；「重新签名」在预览态清空并回到绘制态。
- 「完成」要求至少有一笔，否则轻提示「请先签名」；导出成功后 emit `confirm({ path, width, height })`。
- 不提供撤销；需要重来直接清除。
- 不做手掌防误触；复杂场景由业务外层控制。
- 绘制时阻止页面滚动；画布为空但只读 / 禁用时不响应触摸。

## 5. 导出

- 统一导出 PNG；`backgroundColor="#ffffff"` 为白底签名，`"transparent"` 为透明底。
- 导出尺寸取当前画布像素尺寸；签名为深色笔迹，透明底在暗色背景上可能不可读，默认使用白底。
- H5 / mp-weixin / App 均走 `uni.canvasToTempFilePath`；业务拿 `path` 后自行上传。
- 不直接上传、不依赖任何网络服务。

## 6. 自检清单

- [ ] 画布是内容层标准材质，未使用玻璃或渐变
- [ ] 默认 180px 高、圆角 12、白底、内描边
- [ ] 触控 / 鼠标都能画，绘制时页面不滚动
- [ ] 清除 / 重新签名 / 完成的状态正确，完成前必须有笔画
- [ ] 导出 PNG 可显示、可重新签名，透明底行为符合配置
- [ ] 只读 / 禁用 / 导出中状态正确
- [ ] 暗黑下卡片与占位可读，画布保持白纸；占位文字固定浅灰
- [ ] 尺寸全部 `px`，未使用 `rpx`
- [ ] H5 与 mp-weixin 编译、运行验证
