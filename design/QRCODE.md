# QR Code 规范（强制 · lingyun-qrcode）

> 前端二维码：组件内置 QR 编码器生成矩阵，Canvas 绘制；支持颜色、纠错级别、边框与图片导出。
> 用于取货码、活动核销、商品 / 批次码。

## 1. 依赖与结构

- 运行时依赖：无第三方 npm 包。QR 编码器已移植到组件内（`components/lingyun-qrcode/qrcode.ts`，纯 JS，无 DOM / Node API）；只在本地生成矩阵，不请求网络。
- 结构：白色圆角外框（8px 内边距）+ Canvas 二维码 + 空态 / 错误占位。
- 二维码属于**内容层**，不使用 Liquid Glass；外框用标准白底 + 0.5px 描边。
- 不内置 logo、不内置保存到相册；图片导出由 `toTempFilePath()` 交给业务。

## 2. 尺寸

| 项 | 规格 |
|----|------|
| Canvas | 默认 180px，可配置 80–480px |
| 外框内边距 | 8px |
| 外框圆角 | 16px |
| Canvas 圆角 | 8px（只裁外框，不进入二维码数据区） |
| 静区 | `border` 默认 4 个模块；建议 ≥4 |
| 默认前景色 | `#000000` |
| 默认背景色 | `#ffffff` |
| 纠错级别 | `M` 默认，可选 `L` / `M` / `Q` / `H` |
| 空态 / 错误 | 13/18，Tertiary / System Red，居中 |

- 模块按 `Math.round` 对齐像素，避免半像素模糊；深色模块用 `fillRect` 铺满。
- 内容过长导致编码失败时显示错误占位，并抛 `error`。

## 3. 状态

| 状态 | 表现 |
|------|------|
| 有内容 | Canvas 绘制二维码，白底 + 静区 |
| 空内容 | 白色占位「暂无二维码」 |
| 生成失败 | 白色占位「二维码生成失败」（红色） |
| 自定义颜色 | 前景 / 背景透传；必须保证对比度 |
| 高纠错 | `ecc=H`，模块更多、尺寸更密 |

## 4. 交互与导出

- `value` / `size` / `ecc` / `border` / 颜色变化时自动重绘。
- `ready` 返回 `{ size, version, modules }`；`error` 返回 `{ message }`。
- `refresh()` 手动重绘。
- `toTempFilePath()`：H5 返回 PNG data URL，小程序 / App 返回临时文件路径；无内容 / 错误时 reject。
- 不在组件内下载 / 保存相册，避免权限与平台差异；业务拿到路径后自行处理。

## 5. 暗黑与可扫描性

- 二维码始终白底黑码（或高对比自定义色），**不要**跟随暗黑反色；外框可跟随页面背景。
- 不要缩小静区到 0；不要用低对比色（如浅灰前景）。
- 圆角只作用于外框 / Canvas 边缘，不裁进二维码数据区。
