# Notice Bar Demo

对应页面：`src/pages/demo/notice-bar.vue`

## 区块

1. `hero`：标题 Notice Bar + 说明「非模态通知条 · 信息 / 成功 / 警告 / 错误」。
2. `四种状态`：info / success / warning / error 各一条。
3. `操作与关闭`：`actionText` + `closable`，演示 `action` / `close`。
4. `多行 / 自定义图标`：`multiline` + `icon="location"`。
5. `最近操作`：操作 / 关闭事件。

## 规范

- 组件规格见 [`NOTICE_BARS.md`](../../NOTICE_BARS.md)。
- 页面只负责示例状态。
