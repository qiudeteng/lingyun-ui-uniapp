# Tooltip 规范（强制 · lingyun-tooltip）

> 轻量说明气泡：H5 悬停 / 点击，移动端长按 / 点击；复用 `lingyun-popover`。

## 1. 结构

```text
Tooltip
├── 触发器（默认插槽，inline-flex）
└── lingyun-popover（无遮罩）
    └── 文本 / 自定义内容
```

- 面板复用 `lingyun-popover` 的 Liquid Glass 材质、箭头与定位；不另造浮层。
- 无遮罩、不可点遮罩关闭；Tooltip 只做说明，不建议放可交互内容（需要交互请用 Popover）。
- 触发器撑满自身内容，不强制块级。

## 2. 尺寸

| 项 | 规格 |
|----|------|
| 文本 | 13/18，Label |
| 最大宽度 | 240px |
| 面板宽度 | 默认跟随触发器，Popover 限制 160–280 |
| 箭头 | 默认显示 |
| 显示延迟 | 120ms |
| 隐藏延迟 | 80ms |
| 移动端长按 | 约 2.2s 后自动收起 |

## 3. 触发

| 方式 | 行为 |
|------|------|
| `trigger="hover"` | H5 鼠标进入显示、离开隐藏；移动端点击切换，长按显示 |
| `trigger="click"` | 点击切换，所有平台一致 |
| 禁用 | 不显示、不拦截事件 |

- H5 默认悬停；触屏没有 hover 时用点击 / 长按兜底。
- Tooltip 不抢触发器本身的点击行为；触发器是按钮时，按钮仍可正常点击。
- `showDelay` / `hideDelay` 可调。

## 4. 方向

- `placement`：`top` / `bottom` / `left` / `right`，由 Popover 自动避开视口边缘并翻转。
- 箭头始终指向触发器；空间不足时面板翻到对侧。
