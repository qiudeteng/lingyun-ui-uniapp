# Banner 规范（强制 · lingyun-banner）

> 营销横幅：图片 / 卡片、标题 / 说明 / 操作 / 关闭。
> 内容层组件，占用页面内容宽度，不铺 Liquid Glass。

## 1. 结构

```text
Banner（圆角卡片）
├── 背景图（可选，aspectFill）
├── 渐隐遮罩（top / bottom / full）
├── 内容层：标题、说明、操作
└── 关闭钮（可选）
```

- 图片横幅文字默认白色；无图片时使用 Label / Secondary。
- 关闭钮固定在右上角；操作按钮在内容底部。
- 默认插槽可完全替换标题 / 说明，操作仍走 `actionText` 或 `#action`。

## 2. 尺寸

| 项 | 规格 |
|----|------|
| 默认高度 | 160px，可配置 |
| 圆角 | 20px |
| 内容内边距 | 16px |
| 标题 | 20/26，600，最多 2 行 |
| 说明 | 13/18，最多 2 行 |
| 操作按钮 | 高 32，圆角 16，左右 12，13/18 600 |
| 关闭钮 | 28px 圆形 |
| 图片 | `aspectFill`，铺满，懒加载 |
| 描边 | 0.5px Separator |

## 3. 遮罩

| overlay | 表现 |
|---------|------|
| `bottom` | 从底部向上黑色渐隐，默认 |
| `top` | 从顶部向下黑色渐隐 |
| `full` | 全图 35% 黑色遮罩 |
| `none` | 无遮罩，业务自行保证对比度 |

- 图片横幅建议至少使用 `bottom` / `full`，保证白字可读。
- 无图片时不画遮罩。

## 4. 交互

- 整卡可点，抛 `click`；操作按钮抛 `action`，关闭抛 `close`。
- `disabled` 时整体 0.5 透明度且不响应。
- 关闭后组件隐藏，可调用 `show()` 重新显示。
- 不自动轮播；多张轮播请用 `lingyun-swiper` 组合。

- [ ] 四种 overlay 可读，默认 bottom

- [ ] click / action / close / disabled / show 正确
