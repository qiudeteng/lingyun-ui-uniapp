# Accordion 规范（强制 · lingyun-accordion）

> 折叠分组：单开 / 多开、标题 / 副标题 / 自定义内容。
> 内容层分组卡片，不铺 Liquid Glass。

## 1. 结构

```text
折叠分组（分组卡片）
└── 折叠项 × n
    ├── 标题 / 副标题 + 箭头
    └── 展开内容（文本或自定义插槽）
```

- 整个分组是一张标准卡片；每项不是独立卡片。
- 分割线内缩 16px，仅项与项之间；最后一项不画。
- 内容直接渲染（不做高度动画），避免动态内容测量抖动。

## 2. 尺寸

| 项 | 规格 |
|----|------|
| 卡片圆角 | 16px |
| 卡片描边 | 0.5px Separator |
| 头部最小高度 | 52px |
| 头部内边距 | 12px 16px |
| 标题 | 17/22，400；展开时 600 |
| 副标题 | 13/18，Secondary |
| 箭头 | 16px；展开旋转 180° |
| 内容内边距 | 0 16px 14px |
| 内容文本 | 15/22，Secondary，可换行 |
| 分割线 | 0.5px，左缩 16px |
| 按下态 | Fill Tertiary 背景 |
| 禁用项 | 0.4 透明度，不响应 |

## 3. 状态与模式

| 模式 | `v-model` | 行为 |
|------|-----------|------|
| 单开（默认） | `string` | 同时只展开一项；再次点击收起 |
| 多开 | `string[]` + `multiple` | 可同时展开多项 |

- 点击头部切换；`disabled` 项不响应。
- 提供 `openAll()` / `closeAll()`（仅多开）供批量操作。
- `change` 返回 `{ key, open, openKeys }`；批量操作 key 为空。
- `#content` 插槽作用域 `{ item, index, open }`，可放列表、标签或按钮。
