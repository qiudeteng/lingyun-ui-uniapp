# lingyun-hud

盖住操作的加载提示。业务里用 `uni.showLingyunHud`。

## 示例

```vue
uni.showLingyunHud('提交中')
uni.hideLingyunHud()
```

## 属性

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `show / modelValue` | 是否显示 | — |
| `text` | 文案 | '' |
| `maskClosable` | 点遮罩关闭 | false |
