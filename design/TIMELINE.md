# Timeline 规范（强制 · lingyun-timeline）

> 纵向时间线：订单轨迹、操作日志、审批记录。
> 时间 + 标题 + 说明 + 状态圆点 / 图标，内容层展示。

## 1. 结构

```text
时间线（内容层，非玻璃）
├── 左侧轨道（24px）
│   ├── 连接线（2px）
│   └── 状态圆点（12px / 图标 24px）
└── 右侧内容
    ├── 时间
    ├── 标题
    └── 说明 / 额外插槽
```

- 不做左右交替时间线；窄屏统一左轨 + 右内容，保证可读。
- 连接线位于圆点下方，圆点在上层；最后一项不画连接线。
- 内容层标准材质，不铺 Liquid Glass。

## 2. 尺寸

| 项 | 规格 |
|----|------|
| 轨道宽 | 24px |
| 圆点 | 12px；有图标时 24px 圆底 + 14px 白色图标 |
| 连接线 | 2px，距左 11px；从圆点下方到下一项 |
| 轨道与内容间距 | 12px |
| 每项底部间距 | 20px；最后一项 0 |
| 时间 | 12/16，Secondary |
| 标题 | 15/20，500；进行中 600；错误红色 |
| 说明 | 13/18，Secondary，可换行 |
| 空态 | 15/20，Tertiary，上下 24px |

## 3. 状态

| 状态 | 圆点 | 标题 |
|------|------|------|
| `default` 默认 | Fill Tertiary 12px | Label / 500 |
| `active` 进行中 | 主色 12px | Label / 600 |
| `success` 成功 | System Green | Label / 500 |
| `warning` 警告 | System Orange | Label / 500 |
| `error` 错误 | System Red | System Red |

- 有 `icon` 时圆点变为 24px 实心底 + 白色图标，底色按状态 / 自定义色。
- 每项可用 `color` 覆盖圆点颜色；不改变标题颜色。
- 状态只影响圆点与标题，不改变连接线颜色（连接线保持 Separator）。

## 4. 交互

- 默认只读展示；`clickable` 时整项可点，抛 `item-click({ key, index, item })`。
- 点击态透明度 0.72；没有选中态，当前进度由 `status="active"` 表达。
- `#icon` 替换默认圆点内容，作用域 `{ item, index, status }`。
- `#extra` 可在说明下方放操作 / 标签；`#empty` 自定义空态。
- `emptyText` 默认「暂无记录」。
