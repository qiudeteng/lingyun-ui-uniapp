# Combobox 规范（强制 · lingyun-combobox）

> 可搜索选择：字段触发 + Popover 搜索列表。
> 用于门店、配送方式、状态等单选场景。

## 1. 结构

```text
Combobox
├── 触发字段
│   ├── 标签 / 当前值 / 占位
│   ├── 清除钮（可选）
│   └── 下拉箭头
└── Popover（透明遮罩）
    ├── 搜索框
    ├── 选项列表（scroll）
    └── 空态
```

- 触发器是内容层标准字段；下拉面板复用 Popover 玻璃。
- 透明遮罩拦截点击关闭，不制造暗色。

## 2. 尺寸

| 项 | 规格 |
|----|------|
| 触发字段 | 最小高度 52，内边距 8×12，圆角 12 |
| 标签 | 12/16，Secondary |
| 当前值 / 占位 | 15/20；占位 Tertiary |
| 清除钮 | 24px 圆形 |
| 箭头 | 16px，展开旋转 180° |
| 搜索框 | 高 36，圆角 10，Fill Tertiary |
| 选项行 | 最小 52，左右 10，圆角 10 |
| 选项标题 | 15/20，Label |
| 选项说明 | 12/16，Secondary |
| 列表最大高度 | 240px（可配置） |
| 空态 | 13/18，Tertiary，上下 20 |

## 3. 状态

| 状态 | 表现 |
|------|------|
| 空 | 显示占位 |
| 已选 | 字段显示选项 label，列表对应项高亮 + 勾选 |
| 展开 | 字段 1px 主色描边，箭头旋转 |
| 搜索 | 按 label / description 过滤 |
| 无结果 | 显示 `emptyText` |
| 禁用 / 只读 | 0.5 透明度，不打开 |

## 4. 交互

- 点击字段打开 / 收起；透明遮罩点击关闭。
- 打开后自动聚焦搜索框；小程序键盘抬起时，Popover 以键盘高度作为底部内缩重新定位，列表缩短（上限 160px），避免被键盘遮挡。
- 点击选项选择并关闭；禁用项不可选。
- `clearable` 时清除钮清空为 `null` 并关闭。
- 回车（搜索框）选择第一条可选项。
- 搜索值变化抛 `search`；打开 / 关闭抛 `open` / `close`。
