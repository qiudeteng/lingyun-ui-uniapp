# Calendar 规范（强制 · lingyun-calendar）

> 独立日历：单选 / 日期范围、月份切换、今天、标记与禁用日期。
> 用于配送日期、促销日历、生产排期。

## 1. 结构

```text
日历（内容层标准卡片）
├── 头部：年月标题 + 今天 + 上月 / 下月
├── （范围模式）区间提示
├── 星期表头
└── 6 × 7 日期网格
    └── 复用 lingyun-picker-cal-day：日期 / 农历 / 角标 / 圆点 / 选中 / 今天 / 禁用
```

- 固定 42 格，首尾用相邻月真实日期补齐（灰色不可点），保证周对齐。
- 内容层使用标准分组卡片，不铺 Liquid Glass。
- 选中、今天、禁用、区间底纹都由日历负责；不要另造日期单元格。

## 3. 状态与交互

| 状态 | 表现 |
|------|------|
| 单选 | 点击日期回写 `YYYY-MM-DD` |
| 范围开始 | 点击第一日，只回写 `[start]`，提示「请选择结束日期」 |
| 范围完成 | 点击第二日回写 `[start, end]`；若早于开始日自动交换 |
| 今天 | 头部「今天」跳到当前月，不改变已选值 |
| 禁用 | 超出 `min` / `max`、`disabledDates`、相邻月补位日不可点 |
| 标记 | `marks` 支持角标文字 / 红橙绿圆点，并让日期进入紧凑布局 |
| 农历 | `showLunar` 时在数字下方显示农历 / 节气 |

- 头部箭头切换月份，并抛 `month-change`；到达 min / max 月份时对应箭头置灰。
- 范围终点选择后视图停在终点所在月份，不跳回起点。
- 点击新的日期会重新开始一段范围。
- 不提供周选择 / 农历独立模式；需要时由业务组合。

## 4. 暗黑与自检

- 卡片跟随主题标准材质；日期、农历、星期、区间底纹跟随主题变量。
- [ ] 42 格对齐，周首日可配置，首尾补位灰显不可点
- [ ] 单选取值、范围两次点击、范围交换正确
- [ ] 今天 / min / max / disabledDates / marks 状态正确
- [ ] 农历与角标不挤压日期
- [ ] 月份切换与 `month-change` 正确，min / max 月份箭头置灰
- [ ] 暗黑下可读，区间底纹不盖住选中圆
- [ ] 尺寸全部 `px`，未使用 `rpx`
- [ ] H5 与 mp-weixin 编译、运行验证
