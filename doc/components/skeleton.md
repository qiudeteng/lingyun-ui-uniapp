# lingyun-skeleton

加载中的占位条。

## 示例

```vue
<lingyun-skeleton :rows="3" avatar title />
```

## 属性

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `rows` | 正文行数 | 3 |
| `avatar` | 显示头像占位 | false |
| `title` | 显示标题占位 | true |
