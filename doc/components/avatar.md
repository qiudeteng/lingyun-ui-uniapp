# lingyun-avatar

头像。没有图片时显示文字（通常是名字首字）。

## 示例

```vue
<lingyun-avatar src="/static/me.jpg" size="md" />
<lingyun-avatar text="齐" size="lg" />
```

## 属性

| 属性 | 说明 | 默认值 |
| --- | --- | --- |
| `src` | 图片地址 | '' |
| `text` | 无图时的文字 | '' |
| `size` | `sm` / `md` / `lg` | md |
| `backgroundColor` | 底色 | '' |
