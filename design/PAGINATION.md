# Pagination 规范（强制 · lingyun-pagination）

> 分页控件：总数、页码窗口、上一页 / 下一页、简单模式、小尺寸。
> 内容层控件，不铺 Liquid Glass。

## 1. 结构

```text
分页
├── 总数文案（可选）
└── 页码区
    ├── 上一页
    ├── 页码按钮 × n（含省略号）
    └── 下一页
```

## 2. 尺寸

| 项 | 规格 |
|----|------|
| 总数 | 13/18，Secondary |
| 页码按钮 | 32×32，圆角 8，15/20 |
| 小尺寸 | 28×28，圆角 7，13/18 |
| 按钮间距 | 4px |
| 当前页 | 主色实心底 + 白色文字 600 |
| 悬停 / 按下 | Fill Tertiary 底 |
| 省略号 | 13/20，Tertiary；可点击向前 / 后跳若干页 |
| 上一页 / 下一页 | 32px 方形，左右图标；到头置灰 0.3 |
| 简单模式 | 仅「上一页 / 当前页 / 总页数 / 下一页」 |
| 禁用 | 整体 0.4，不响应 |

## 3. 页码窗口

- 总页数 ≤ `maxButtons`（默认 7）时显示全部页码。
- 超过时显示：首页、左侧省略号（可选）、当前页附近、右侧省略号（可选）、末页。
- 当前页靠前 / 靠后时自动压缩另一侧省略号。
- `maxButtons` 限制 5–11，实际内页数量按窗口计算。

## 4. 行为

- `v-model` 绑定当前页；点击页码或上一页 / 下一页回写并抛 `change({ page, pageSize, pageCount })`。
- `total` / `pageSize` 变化时当前页自动限制在 1–总页数，但不主动回写。
- `hideOnSinglePage` 时总页数 ≤1 整块隐藏。
- `showTotal=false` 隐藏总数；`totalText` 可覆盖文案。
- `simple` 只显示当前页 / 总页数，适合窄屏。
- `disabled` 时不响应任何点击。
