# Barcode 规范（强制 · lingyun-barcode）

> 一维条码：Code128 / Code39 / EAN-13，Canvas 绘制与图片导出。
> 用于取货码、商品码、批次码。

## 1. 依赖与结构

- 运行时依赖：`etiket` 的纯编码器（Code128 / Code39 / EAN13），返回条宽数组；无 DOM / Node API。
- 结构：白色圆角外框（8px 内边距）+ Canvas（条空 + 可选文字）+ 空态 / 错误占位。
- 条码属于**内容层**，不使用 Liquid Glass；外框标准白底 + 0.5px 描边。
- 不内置 logo / 保存相册；导出交给业务。

## 2. 码制

| 格式 | 说明 |
|------|------|
| `CODE128` | 自动字符集（A/B/C），支持字母、数字、常见符号；默认 |
| `CODE39` | 43 字符集，可选校验位；适合短编号 |
| `EAN13` | 12 或 13 位数字，12 位自动计算校验位 |

- Code128 可通过 `code128Charset` 强制 A/B/C。
- Code39 可通过 `code39CheckDigit` 追加校验位。
- EAN13 导出 / 展示使用包含校验位的 13 位数字。

## 3. 尺寸

| 项 | 规格 |
|----|------|
| 模块宽度 | 默认 2px，可配置 1–6px |
| 总高 | 默认 80px，可配置 48–200px |
| 条区高度 | 总高 − 文字区 18px（`showValue=false` 时占满） |
| 文字 | 默认 12px，9–18px，条码下方居中 |
| 静区 | 默认左右各 10 个模块，0–20 |
| 外框内边距 | 8px |
| 外框圆角 | 16px |
| Canvas 圆角 | 8px（只裁外框） |
| 默认前景 / 背景 | `#000000` / `#ffffff` |

- 宽度 = (静区 × 2 + 条空模块总数) × 模块宽度；内容较长时适当降低 `moduleWidth`。
- 条空按像素取整绘制，避免半像素模糊；不要用 CSS 缩放已绘制的条码。

## 4. 状态与交互

| 状态 | 表现 |
|------|------|
| 有内容 | 绘制条空与文字，白底静区 |
| 空内容 | 白色占位「暂无条件码」 |
| 生成失败 | 白色占位「条码生成失败」（红色），抛 `error` |
| 自定义颜色 | 前景 / 背景透传；必须保持高对比 |
| 隐藏文字 | `showValue=false`，条区占满高度 |

- `value` / `format` / `moduleWidth` / `height` / 静区 / 颜色 / 文字变化时自动重绘。
- `ready` 返回 `{ format, text, modules, width, height }`。
- `toTempFilePath()`：H5 返回 PNG data URL，小程序 / App 返回临时文件路径。
- 生成失败时 `error` 返回 `{ message }`。

## 5. 可扫描性

- 保持白底深色条码；不要跟随暗黑反色，不要用低对比色。
- 静区建议 ≥10 个模块；不要裁掉左右静区。
- EAN13 使用自动校验位；Code39 输入不合法时直接报错。
- 条码较宽时优先减小 `moduleWidth` 或缩短内容，避免页面横向溢出。
