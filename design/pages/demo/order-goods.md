# design/pages/demo/order-goods

对应源码：`src/pages/demo/order-goods.vue`（标准页：`src/uni_modules/lingyun-ui-page/components/lingyun-order-goods`）

参考美团外卖点单页的左右布局，做一个数据驱动的「订单商品加购」标准页：

- 店铺头：Banner（支持 `#banner` 插槽，演示用真实蛋糕图片）+ 悬浮店铺卡片（logo、名称、评分、月售、配送时长、提示条）；`bannerHeight=0` 时不显示 Banner，店铺卡片直接从工具栏下方开始；暗黑下页面 / 分类栏为黑色，卡片为 `#1c1c1e`，和浅色一样保持卡片层级
- 主体：左侧 88px 分类导航，右侧商品列表；分类名左侧可带 14px 小图标（后台 URL `iconSrc` 或 `icon` 字形），图标作为行内元素参与换行，分类名最多两行；购物车数字角标浮在右上角，不影响换行。点击分类右侧平滑滚动，右侧滚动时左侧自动高亮并滚进可视区
- 左侧选中背景为圆角胶囊，切换时上下滑动（类似 tabbar 透镜），点击的文字做轻微回弹；分类有已选商品时右上角显示数量角标
- 商品行：76px 图片（无图用名称首字兜底）、名称最多两行、规格 / 销量、招牌角标、现价 / 划线原价、右下角主色加购钮
- 商品数据扩展：`details` 多行说明（发货仓库、规格描述、截单时间、预计配送）、`priceUnit` 价格后缀、`quantityUnit` 步进器单位、`specs` 规格（支持 `stock`）、`attributeGroups` 属性分组（必选 / 可选、`max` 1 单选 / >1 多选按数量合计，选项支持 `enabled: false`，规格与属性都支持 `image`）；售罄显示「商品已售罄」；多规格主列表显示最低价 + `起`；`priceDecimals` 控制价格小数位
- 加购按数据自动区分四种：① 无规格无属性：点 `+` 直接加购并变步进器；② 只有规格：点 `+` 弹出规格列表 Sheet，每个规格独立加减，再次打开显示已选数量；③ 规格 + 属性：弹出组合 Sheet，先单选规格，再按分组选属性，底部对当前「规格 + 属性」组合加购 / 步进；④ 只有属性：同 ③ 但不显示规格。选择器在页面专用子组件 `lingyun-order-goods-variant-sheet.vue` 内，样式也随组件抽离；规格 / 属性带 `image` 时用 4:3 小图卡片（一行 3 个）：名称压在图片底部半透明条上、单行截断，卡片下部只保留价格与选择控件；单选组用勾选圆点，多选组用 `+` / 步进器且同一选项可选多个，无图多选组用文字行 + 步进器
- 纯规格列表 Sheet 标题为主商品名称，内容只保留规格列表；规格行保留规格自己的 76×76 图片并与文字顶部对齐，价格、库存和加减控件在右侧
- 必选属性分组打开时默认选中第一个可用选项，打开即可直接加购；可选分组保持为空。组合 Sheet 每次打开都重置为默认（第一个可用规格 + 必选分组第一个可用选项），不保留上次选择；点「加入购物车」写入购物车后自动关闭
- 组合 Sheet 底部固定高度：左侧当前规格价 + 提示（必选 / 库存不足 / 已选件数），右侧「加入购物车」；当前组合已在购物车时改为步进器，加减不关闭 Sheet，切换规格 / 属性后按新组合是否已选重新显示按钮或步进器；规格卡片始终显示价格，库存用「剩 N」/「售罄」角标
- 库存示例：经典蛋糕 6 寸剩 5 / 8 寸剩 2，巧克力脆皮 8 寸售罄，马卡龙（无规格）售罄，提拉米苏剩 3，拿铁（只有属性）剩 5；配件「餐具」`enabled: false` 展示禁用态
- 商品详情：点商品图 / 名称打开 `lingyun-sheets` 大模式 Sheet（对齐参考图，去掉评价）：4:3 头图、价格 / 月售 / 划线原价、商品名与「商品介绍」；加购按钮固定在 Sheet 底部 `footer` 操作区（移动端 / 宽屏一致），并与列表联动：普通商品已加购显示步进器，规格 / 属性商品显示「选规格 / 选属性」+ 总数量角标，点击收起详情并打开选择 Sheet，售罄置灰；多图时使用 `lingyun-swiper`：大图可左右滑动 / 自动轮播，底部横排缩略图作为指示器，点击切换；移动端头图通过 `bleedTop` 延伸到面板顶部、关闭钮浮在图片左上角；宽屏（≥690）左侧为图片 + 图下商品介绍、右侧为价格 / 名称，商品介绍自动填满左栏剩余高度（`contentFill`），标题固定、内容在自身区域滚动，图片列固定 42% 宽，图片左距与右侧文字右距一致；购物车数量增加时底部购物车圆钮放大回弹
- 底部购物车栏：复用 `lingyun-goods-nav` 的 `variant="cart"`（悬浮玻璃胶囊、主色购物车圆钮 + 数量角标、合计价格、配送费、起送价 / 去结算钮）；购物车固定悬浮在列表之上，左侧分类栏与右侧商品列表通高到页面底部，列表尾部留出购物车让位，商品从购物车底部穿过
- 已选商品：使用 `lingyun-goods-nav` 的 `detail` 详情，详情与购物车是同一张玻璃卡、展开时整卡向上增高；左上角关闭钮，点卡片外遮罩收起，结算钮始终可点；高度随内容自动撑开，超过视口上限后内部滚动，逐项步进器 + 清空。规格 / 属性组合按行显示，每行一个选择，缩略图优先取带图的属性、其次规格图、最后商品图，图片 56×42（4:3）
- 演示数据覆盖四种商品：八喜经典冰淇淋蛋糕（规格 + 上层 / 下层口味 + 配件）、巧克力脆皮冰淇淋蛋糕（只有规格）、拿铁（只有温度 / 糖度 / 加料属性）、提拉米苏（无规格无属性）
- 演示数据使用真实的蛋糕图片（Unsplash）；微信小程序真机需把 `images.unsplash.com` 加入 downloadFile 合法域名，或在开发者工具勾选「不校验合法域名」
- 数据全部走 props：`store` / `categories` / `v-model` 购物车；结算、返回抛事件；规格 / 属性在页面内置 Sheet 中完成
- 顶部工具栏右侧「筛选」按钮（`tune` 图标）与主题钮同组，点击弹出筛选面板：加载模式 chips（自动加载 / 全部加载 / 分段加载 / 按分类加载）+ Banner 开关 + 高度滑块（60–300px，拖动实时预览）+ 完成；分段先渲染前 2 个分类、滚到底部追加；按分类只渲染当前分类并模拟加载态
- 顶部工具栏：demo 开启 `show-toolbar`（标题「点单」）+ `searchable`，并设 `auto-top-inset="false"`：Banner 顶到页面顶部、垫在透明工具栏下，头部只保留这一层工具栏，不再出现 Banner 自带的返回钮与标题；Banner 顶部按主题渐隐保证标题可读。小程序顶栏由 `lingyun-app-page` 处理状态栏安全区。点搜索进入搜索态：隐藏 Banner / 店铺卡片 / 左侧分类，列表切换为搜索结果（按原分类分组、显示结果数 / 未输入提示 / 无结果空态），搜索结果可直接加购、改数量或打开商品详情；关闭搜索回到原列表并定位当前分类，顶部留白自动恢复
- 角标：商品标签、详情页商品名旁角标、分类栏分类角标 / 数量角标统一使用 `lingyun-badge size="small"`（18px 高）；商品标签与详情角标为 `color="orange"`，不再使用自定义小 `text`
