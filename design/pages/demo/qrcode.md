# QR Code Demo

对应页面：`src/pages/demo/qrcode.vue`

## 区块

1. `hero`：标题 QR Code + 说明「二维码 · 前端生成 · 颜色 / 纠错级别 / 图片导出」。
2. `基础二维码`：取货码链接，默认 180px / M 纠错；右侧显示内容。
3. `自定义颜色 · 高纠错`：220px、`ecc=H`、深蓝前景 + 浅蓝背景。
4. `动态内容`：输入框实时修改二维码内容，空内容显示占位。
5. `导出图片`：调用 `toTempFilePath()`，H5 显示 data URL，小程序 / App 显示临时路径。
6. `最近操作`：显示生成版本 / 模块数与导出结果。

## 规范

- 组件规格见 [`QRCODE.md`](../../QRCODE.md)。
- 页面只负责示例内容与导出展示，不承载二维码编码逻辑。
