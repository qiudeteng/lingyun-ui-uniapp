# Signature Demo

对应页面：`src/pages/demo/signature.vue`

## 区块

1. `hero`：标题 Signature + 说明「手写签名 · 触控 / 鼠标 / 导出 PNG」。
2. `基础签名`：默认 180px 白底画布，演示绘制、导出、清除、重新签名；显示最近生成的 PNG 地址。
3. `自定义笔迹`：`penColor=#0088ff`、`penWidth=5`、`height=220`，演示配置化笔迹与高度。
4. `只读 / 禁用`：用 `src/static/demo/signature-sample.png` 预填签名，分别展示只读与禁用。
5. `最近操作`：显示开始签名、完成一笔、导出尺寸、清除、导出失败等事件。

## 交互

- H5 可用鼠标拖拽，移动端用触控；绘制时页面不滚动。
- 「完成」导出 PNG 并回写 `v-model`，同时把预览覆盖到画布上；没有笔画时提示「请先签名」。
- 已签名后操作区变为「重新签名」，点击清空并回到绘制态。
- 只读 / 禁用不显示操作区，只展示签名图片。

## 规范

- 组件规格见 [`SIGNATURE.md`](../../SIGNATURE.md)。
- 页面只负责示例状态与事件展示，不承载 Canvas 绘制逻辑。
- 示例签名为本地静态 PNG，仅供 demo 回显使用。
