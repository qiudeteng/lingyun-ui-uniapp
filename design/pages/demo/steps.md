# Steps Demo

对应页面：`src/pages/demo/steps.vue`

## 区块

1. `hero`：标题 Steps + 说明「流程步骤条 · 横向 / 纵向 · 完成 / 进行中 / 等待 / 错误」。
2. `横向步骤`：4 步下单流程，`clickable` + `v-model`，底部「上一步 / 下一步」调用 `prev()` / `next()`。
3. `纵向步骤`：4 步审批流程，带说明文字，演示纵向连接线与多行说明。
4. `错误与禁用`：支付失败 `status="error"`，最后一步 `disabled`。
5. `自定义主题色`：`accentColor="#34c759"`，演示主色覆盖。
6. `最近操作`：显示点击步骤后的 `change` 结果。

## 交互

- 点击任意可点击步骤切换当前步；禁用的步骤不响应。
- 横向步骤等宽排列，步骤多时可横向滚动；纵向步骤随页面滚动。
- 默认状态按当前索引推导；显式 `status` 优先。

- 组件规格见 [`STEPS.md`](../../STEPS.md)。
- 页面只负责示例数据与事件展示。
