# design/pages/demo/purchase-order-detail

对应源码：`src/pages/demo/purchase-order-detail.vue`（标准页：`src/uni_modules/lingyun-ui-page/components/lingyun-purchase-order-detail`）

订货单详情演示，数据来自 `src/pages/demo/purchaseOrderDemo.ts`，从订货单列表点卡片进入；也可以直接打开本页（默认展示多批配送的主订货单）。

- 页面壳：`lingyun-app-page`，标题「订货单详情」/ 子订货单「子订货单详情」，开启返回；`body-scroll=false` / `page-scroll=false`，内容区使用内层 `scroll-view`；底部操作栏悬浮在滚动内容上方。
- 主订货单状态头：分组卡片，状态图标（44 圆角方块、状态色浅底）+ 20px 粗体状态标题 + 13px 提示；待付款下方显示「支付剩余 mm:ss」倒计时，超时抛 `payment-timeout` 后订货单转为已取消。底部「实付款 / 需付款 / 订货单金额」与金额。**有子订货单时隐藏整张状态卡**，以子订货单状态为准。
- 配送 / 自提：分组标题 + 静态卡片；配送显示收货人 / 电话 / 地址，自提显示门店 / 电话 / 地址 / 自提时间；无右侧箭头、不可点击。主订货单有子订货单、待审核、待付款时不显示预计送达时间。
- **多批配送（审核拆单）**：主订货单页只显示「子订货单与物流 · N 批」列表，不再展开每个子订货单的完整物流：
  - 每行：子订货单号（13px 600）+ 状态（状态色）+ 发货仓库「发货仓库：北京朝阳仓」；
  - 发货仓库行右侧（整行右对齐）显示预计日期：待发货「预计 11-09 发货」、待收货「预计 11-09 送达」；只显示日期，不带时分；
  - 商品：横向缩略图（52×52、圆角 10、间距 8），最多 3 张，多出显示 `+N`；右侧「共 N 件」与子订货单金额；
  - 只显示最后一条物流日志的说明和时间（时间用 `lingyun-date-text`，保留 MM-DD HH:mm，不显示日志标题；`timeline` 按新到旧，取第一项；说明允许换行，不截断）；
  - 状态色：待审核紫、待付款橙、待发货靛蓝、待收货蓝、已完成绿、已取消灰、退款中红；
  - 「查看子订货单详情」+ 右箭头，整行可点，抛 `sub-purchase-order-click`。
- 子订货单详情：复用同一个 `lingyun-purchase-order-detail`，通过 `buildLingyunPurchaseOrderSubDetail(parent, sub)` 拍平后展示单订货单布局——状态头、配送地址、该子订货单商品、子订货单金额、完整物流时间线、订货单信息（含所属订货单 / 发货仓库 / 仓库地址 / 仓库电话）与子订货单操作。子订货单详情不显示预计送达时间。子订货单页隐藏主题钮（`showThemeSwitch=false`），让「子订货单详情」标题在微信小程序下不被截断。
- 单笔订货单（待审核 / 待付款 / 待发货 / 已完成 / 已取消 / 退款中）：没有子订货单时仍显示商品清单与完整物流时间线；已完成示例为自提，验证配送 / 自提两种卡片。
- 商品清单：商品数 > 1 时默认折叠——分组标题带总件数，卡片内横向展示前 3 张 52px 缩略图（多出 `+N`），底部「查看详情」；展开后为完整列表（每行 72px 圆角图、名称、规格、单价 / 划线原价、数量），底部变「收起详情」；只有 1 个商品时直接显示完整列表，不显示切换按钮，切换订货单自动回到折叠态。详情不显示商品的招牌 / 热门等标签。
- 金额明细：商品合计、配送费、优惠、优惠券、实付 / 需付款；最后一行加粗放大，上方分割线。
- 物流信息：分组标题 + 卡片；顶部显示承运服务商（京东快递 / 顺丰 / 自营物流等）与第三方快递单号（带「复制」，自营物流无单号）；下方时间线仅放物流节点（已出库 / 配送中 / 已签收），不放支付 / 下单 / 审核等订货单操作日志。仅审核通过后显示；待审核 / 待付款不渲染。活动节点 10px 蓝点 + 3px 光晕；时间、标题、说明；第一项默认高亮，可传 `active` 覆盖。
- 订货单信息：订货单编号 + 「复制」、下单 / 支付时间、支付方式、备注、自定义行；子订货单详情额外显示所属订货单与仓库信息。
- 底部操作栏：悬浮玻璃胶囊（左右 12、底部 8 + 安全区、高 62、圆角 31、`lingyun-glass-control`），绝对定位悬浮在滚动内容上方（内容从下方穿过、尾部留出胶囊高度）；左侧显示需付款 / 实付款金额，右侧操作按钮。待发货 / 待收货 / 退款中不显示底部操作栏；待付款保留「取消订货单 / 去支付」；已完成保留「申请售后 / 再来一单」，已取消只保留「再来一单」（订货单不允许删除），待审核为取消订货单。操作只抛 `action`，由 demo 弹 Toast。
- 内层 `scroll-view` 把滚动位置上报给 `lingyun-app-page`，内容从顶栏下方穿过（`scrollUnderToolbar` 默认开启），顶栏从透明渐显 Liquid Glass（与设计规范一致）。
- 返回钮默认返回上一页（`autoBack=true`）；页面需要自定义返回时传 `autoBack=false` 并监听 `back`。
- 页面重新进入 / 切换订货单时内部滚动回到顶部，避免 H5 恢复上一次的内部滚动位置。
- 内容宽屏最大 720px 居中；状态卡与卡片圆角 20px，分组标题使用 `lingyun-group-header`，与卡片内容对齐。
- 图片沿用 order-goods demo 的 `images.unsplash.com`；微信真机需配置 downloadFile 合法域名，或在开发者工具勾选「不校验合法域名」。
