# Tooltip Demo

对应页面：`src/pages/demo/tooltip.vue`

## 区块

1. `hero`：标题 Tooltip + 说明「轻量说明 · H5 悬停 / 移动端长按或点击」。
2. `基础 Tooltip`：hover 触发，展示与隐藏事件。
3. `四个方向`：top / bottom / left / right。
4. `点击触发`：`trigger="click"`。
5. `自定义内容 / 禁用`：`#content` 插槽与 disabled。
6. `最近操作`：show / hide。

## 规范

- 组件规格见 [`TOOLTIPS.md`](../../TOOLTIPS.md)。
- H5 鼠标悬停；移动端点击 / 长按。
